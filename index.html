Info z videa

JavaScript je interpretovaný narozdíl od programmovacích jazyků, které jsou kompilované, například C/C++/C# podle kterých je i částečně syntaxe.

Součástí jazyka je i garbage collector, který se stará o odstraňování nepoužívaných proměných.

Jeden z prostředků, který se používá v JavaScriptu, je WebAsembly, který soluží jako prostředník mezi kompilovaným kódem a prohlížečem. Kód, například v C#, je možné přeložit do WebAsembly, který dokáže prohlížeč použít.

Pokud by jsme chtěli JavaScript použít na server jednou z možností je Node.js

Promise, Resolve, Await

Promise - Soluží jako příslib vrácení hodnoty.

Resolve - Je funkce která vrací hodnotu Promise jako úspěšnou.

Await - Je označení pro asynchroní fuknce a je potřeba počkat na vrácenou hodnotu.
